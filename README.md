# ServiceWatchdog — монитор служб Windows

Небольшая программа в трее: следит за отмеченными службами Windows и запускает их,
если служба не работает дольше заданного таймаута (по умолчанию 30 с).

## Возможности

- После запуска сразу сворачивается в трей; двойной клик по значку открывает окно.
- В окне — список служб с чекбоксами, поиск и фильтр «Только отмеченные».
- Таймаут настраивается в окне (10–3600 с) и применяется сразу.
- Крестик и «Свернуть» прячут окно в трей; выйти можно только через «Выход» в меню значка.
- Автозапуск — чекбокс «Запускать при входе в Windows» (задание Планировщика с наивысшими
  правами: без запроса UAC, без ограничения времени работы).
- Повторный запуск exe не создаёт второй экземпляр, а открывает окно уже запущенного.

## Восстановление службы

Опрос каждые 5 секунд. Если служба не в состоянии «Выполняется» дольше таймаута:

| Состояние | Действие |
|---|---|
| Остановлена | запуск |
| Приостановлена | возобновление |
| Зависла при запуске/остановке | принудительное завершение процесса и запуск; если процесс общий для нескольких служб (svchost), завершение пропускается |

При неудаче попытки повторяются каждый таймаут; одинаковое уведомление в трее показывается один раз.

## Файлы

Всё хранится в `C:\ProgramData\ServiceWatchdog\`:

- `services.txt` — отмеченные службы;
- `timeout.txt` — таймаут в секундах;
- `watchdog.log` — журнал (при превышении 1 МБ переименовывается в `.old`).

## Сборка

Нужен только .NET Framework 4.8 (есть в Windows 10/11):

```
build.cmd
```

Результат — `bin\ServiceWatchdog.exe`. Программа требует прав администратора (управление службами).
