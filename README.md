# 1CWhatchdog

Программа в трее для рабочих мест Windows:

- **Службы.** Следит за отмеченными службами и запускает их, если служба не работает
  дольше заданного таймаута (по умолчанию 30 с).
- **Разрешённые программы.** Не даёт пользователям запускать программы не из списка
  разрешённых (или только записывает такие запуски в журнал).
- **Запрещённые программы.** Не даёт запускать программы из списка запрещённых
  (или только записывает такие запуски в журнал).

## Окно

Двойной клик по значку в трее открывает окно; крестик и «Свернуть» прячут его обратно в трей,
выйти можно только через «Выход» в меню значка. Повторный запуск exe не создаёт второй
экземпляр, а открывает окно уже запущенного.

**Вкладка «Службы»** — список служб с чекбоксами, поиск, фильтр «Только отмеченные», таймаут (10–3600 с).

**Вкладка «Разрешённые программы»:**

- «Контролировать запуск программ» — включает функцию;
- «Завершать программы не из списка» — без этой отметки запуски только записываются
  в журнал. Удобно сначала поработать в этом режиме и посмотреть, что запускается;
- список разрешённых exe: ввести имя, выбрать файл или отметить из запущенных сейчас программ.

Ограничение действует на **всех** пользователей, включая администраторов. Программы
сравниваются по имени exe-файла (`1cv8.exe`). Всегда разрешены программы из папки Windows,
Защитник Windows, WebView2 (его использует сама Windows — поиск в «Пуске», виджеты),
процессы служб и сам 1CWhatchdog.

**Вкладка «Запрещённые программы»** устроена так же: «Запрещать программы из списка»,
«Завершать запрещённые программы» (иначе — только журнал) и список exe. Запрет действует
и на программы из папки Windows (`cmd.exe`, `powershell.exe`, `regedit.exe`, `taskmgr.exe`…)
и важнее списка разрешённых. Процессы служб и сам 1CWhatchdog не трогаются никогда.

## Как устроено

Программа состоит из двух частей (один и тот же exe):

- **Мониторинг** (`1CWhatchdog.exe /monitor`) — работает от имени SYSTEM, стартует при
  загрузке Windows независимо от того, кто вошёл в систему. Перезапускает службы
  и завершает запрещённые программы.
- **Значок в трее** — запускается при входе **любого** пользователя, без прав администратора.
  Показывает состояние служб, журнал и уведомления.

Менять настройки может только администратор: без прав окно открывается в режиме просмотра,
кнопка «Изменить настройки…» открывает его с повышением прав (UAC). Пока открыто окно
настроек, второе окно не появляется.

## Восстановление службы

Опрос каждые 5 секунд. Если служба не в состоянии «Выполняется» дольше таймаута:

| Состояние | Действие |
|---|---|
| Остановлена | запуск |
| Приостановлена | возобновление |
| Зависла при запуске/остановке | принудительное завершение процесса и запуск; если процесс общий для нескольких служб (svchost), завершение пропускается |

При неудаче попытки повторяются каждый таймаут; одинаковое уведомление в трее показывается один раз.

## Установка

1. Запустите `1CWhatchdog.exe`, откройте окно двойным кликом по значку в трее.
2. Нажмите «Изменить настройки…» и подтвердите запрос UAC.
3. Включите «Автозапуск для всех пользователей». Программа скопирует себя в
   `C:\Program Files\1CWhatchdog` и создаст задания Планировщика
   «1CWhatchdog Monitor» (SYSTEM, при загрузке) и «1CWhatchdog Tray» (вход любого пользователя).
4. Отметьте службы и настройте разрешённые программы.

**Обновление с ServiceWatchdog 1.x:** при включении автозапуска старые задания
«ServiceWatchdog …» останавливаются и удаляются, список служб и таймаут переносятся
из `C:\ProgramData\ServiceWatchdog`. Папку `C:\Program Files\ServiceWatchdog` можно удалить вручную.

## Файлы

Всё хранится в `C:\ProgramData\1CWhatchdog\` (запись — только администраторы и SYSTEM,
остальные пользователи — чтение):

- `services.txt` — отмеченные службы;
- `timeout.txt` — таймаут в секундах;
- `allowed.txt` — разрешённые программы (имена exe);
- `denied.txt` — запрещённые программы (имена exe);
- `appcontrol.txt` — включение и режим контроля программ
  (`enabled`, `block` — разрешённые; `deny_enabled`, `deny_block` — запрещённые; значения `0/1`);
- `watchdog.log` — журнал (при превышении 1 МБ переименовывается в `.old`).

## Сборка

Нужен только .NET Framework 4.8 (есть в Windows 10/11):

```
build.cmd
```

Результат — `bin\1CWhatchdog.exe`. Иконки и логотип встраиваются в exe из папки `assets`.
Если PNG в `assets` поменялись, многоразмерный `assets\app.ico` пересобирается командой
`tools\make-icon.cmd`.
