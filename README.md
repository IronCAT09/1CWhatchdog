# ServiceWatchdog — монитор служб Windows

Небольшая программа в трее: следит за отмеченными службами Windows и запускает их,
если служба не работает дольше заданного таймаута (по умолчанию 30 с).

## Возможности

- После запуска сразу сворачивается в трей; двойной клик по значку открывает окно.
- В окне — список служб с чекбоксами, поиск и фильтр «Только отмеченные».
- Таймаут настраивается в окне (10–3600 с) и применяется сразу.
- Крестик и «Свернуть» прячут окно в трей; выйти можно только через «Выход» в меню значка.
- Повторный запуск exe не создаёт второй экземпляр, а открывает окно уже запущенного.

## Как устроено

Программа состоит из двух частей (один и тот же exe):

- **Мониторинг** (`ServiceWatchdog.exe /monitor`) — работает от имени SYSTEM, стартует при
  загрузке Windows и следит за службами независимо от того, кто вошёл в систему.
- **Значок в трее** — запускается при входе **любого** пользователя, без прав администратора.
  Показывает состояние служб, журнал и уведомления.

Менять настройки может только администратор: без прав окно открывается в режиме просмотра,
кнопка «Изменить настройки…» открывает его с повышением прав (UAC).

## Установка

1. Запустите `ServiceWatchdog.exe`, откройте окно двойным кликом по значку в трее.
2. Нажмите «Изменить настройки…» и подтвердите запрос UAC.
3. Включите «Автозапуск для всех пользователей». Программа скопирует себя в
   `C:\Program Files\ServiceWatchdog` и создаст задания Планировщика
   «ServiceWatchdog Monitor» (SYSTEM, при загрузке) и «ServiceWatchdog Tray» (вход любого пользователя).
4. Отметьте службы для мониторинга.

## Восстановление службы

Опрос каждые 5 секунд. Если служба не в состоянии «Выполняется» дольше таймаута:

| Состояние | Действие |
|---|---|
| Остановлена | запуск |
| Приостановлена | возобновление |
| Зависла при запуске/остановке | принудительное завершение процесса и запуск; если процесс общий для нескольких служб (svchost), завершение пропускается |

При неудаче попытки повторяются каждый таймаут; одинаковое уведомление в трее показывается один раз.

## Файлы

Всё хранится в `C:\ProgramData\ServiceWatchdog\` (запись — только администраторы и SYSTEM,
остальные пользователи — чтение):

- `services.txt` — отмеченные службы;
- `timeout.txt` — таймаут в секундах;
- `watchdog.log` — журнал (при превышении 1 МБ переименовывается в `.old`).

## Сборка

Нужен только .NET Framework 4.8 (есть в Windows 10/11):

```
build.cmd
```

Результат — `bin\ServiceWatchdog.exe`.
